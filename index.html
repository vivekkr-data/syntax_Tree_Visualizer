Grammar Summary

program      → statement* EOF
statement    → "let" ID "=" expression ";"
             | ID "=" expression ";"
             | "print" "(" expression ")" ";"
             | "if" "(" expression ")" block
               ("else" block)?
             | "while" "(" expression ")" block
             | expression ";"
block        → "{" statement* "}"
expression   → logical-or
logical-or   → logical-and ("||" logical-and)*
logical-and  → equality ("&&" equality)*
equality     → comparison (("==" | "!=") comparison)*
comparison   → term (("<" | "<=" | ">" | ">=") term)*
term         → factor (("+" | "-") factor)*
factor       → unary (("*" | "/" | "%") unary)*
unary        → ("!" | "-") unary | primary
primary      → NUMBER | STRING | BOOLEAN | ID
             | ID "(" arguments? ")"
             | "(" expression ")"

Built as an interactive compiler-design teaching tool using HTML, CSS, JavaScript, tokenization, recursive-descent parsing, and SVG.
